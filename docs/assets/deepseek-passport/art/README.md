# Pet Sprite Design and Generator

This directory holds the pet's pixel art and the script that produces it. The
script is the source of truth: the PNG files are build output, regenerated by one
command, and safe to delete.

The design is **original artwork**. It is an echo of DeepSeek's brand blue, not a
copy of the DeepSeek logo or of any third-party character.

> **Status:** first-pass design, awaiting product-owner sign-off. Redrawing is
> cheap — edit the geometry constants and re-run the generator.

## Design

A Q-version whale facing right, in three-quarter view: both eyes are visible so
the pet can act, the fluke is at the back left, and a spout appears above the
head when the pet is speaking or happy.

| Property | Value |
| --- | --- |
| Logical grid | 32 × 32 pixels |
| Output size | 64 × 64 pixels (integer 2× scale, so every logical pixel is a 4-pixel square) |
| Orientation | Landscape sprite, right-facing, portrait screen |
| Silhouette | Rounded body, rounder head at the front, two-lobe fluke, small dorsal fin, front pectoral fin, pale belly, light band along the back |
| Face | Two 3 × 3 eyes with 2 × 2 pupils that can look in four directions, a 4-pixel mouth with four shapes, and cheek blush |
| Outline | One logical pixel of dark navy around the body only; decorations such as the spout and the sleep marks are deliberately left unoutlined |

Facing right is deliberate and is explained under
[reference research and independence](#reference-research-and-independence).

## Palette

Eleven opaque entries plus transparency. Kept small on purpose: fewer colours
mean smaller indexed sprite data later.

| Index | Name | Hex | Use |
| --- | --- | --- | --- |
| 0 | transparent | — | Everything outside the sprite |
| 1 | outline | `#101828` | Silhouette border and facial features |
| 2 | body | `#4D6BFE` | Main body — the DeepSeek brand blue |
| 3 | body-dark | `#2B3A8F` | Reserved for depth and shading |
| 4 | body-light | `#7A92FF` | Light band along the back |
| 5 | belly | `#EAF0FF` | Belly and mouth area |
| 6 | eye | `#101828` | Pupils and mouth |
| 7 | eye-white | `#FFFFFF` | Eye whites |
| 8 | blush | `#FF9EB1` | Cheeks |
| 9 | water | `#8FD4FF` | Spout, listening waves, sweat drop |
| 10 | water-light | `#FFFFFF` | Spout highlights |
| 11 | sleep | `#C8D6FF` | Thought bubbles and sleep marks |

## Frames and triggers

| Frame | Trigger |
| --- | --- |
| `idle_a`, `idle_b` | Default state; the pair is a two-frame breathing bob |
| `blink` | Inserted into the idle loop at random intervals |
| `curious` | `UP` / `DOWN` press, or a new notification |
| `listening` | Voice capture active |
| `thinking` | Language-model round trip in flight |
| `working` | An agent task is running; the tail is raised |
| `speaking` | Reply audio playing |
| `happy` | Successful turn, work-mode success |
| `sleeping` | Standby with the screen dimmed |
| `distressed` | Network or provider failure, low battery |

## Reference research and independence

The design was informed by published references and copies nothing from them.

| Finding | Source |
| --- | --- |
| The official brand colour is `#4D6BFE` | DeepSeek's own organisation repository ships a colour swatch whose only fill is that value. The body colour here is exactly it |
| DeepSeek's mark is a whale | Press coverage describes it as a plump bright blue whale, and notes that the whale's eye is lost at small sizes — which is why this pet's eyes are deliberately oversized and high-contrast |
| No official pixel-art mascot exists | The official character is the logo whale only, so this project is not duplicating published artwork |
| The logo whale faces left with its flukes raised at the upper right | A rendered copy of the official logo, viewed directly |

Decisions taken from those findings:

- **Orientation.** This pet faces right. The official logo faces left, and matching it exactly would move the character toward the logo silhouette, which is the part most protected by DeepSeek's brand rules. Facing right also points the pet into the screen content. It is a one-constant change if the owner prefers the logo orientation — see the note under Design.
- **Tail means working.** DeepSeek's own harness uses an animated whale tail as its "agent is working" indicator. The `working` frame follows that convention instead of inventing a different one.
- **Nothing is traced.** The official silhouette was not traced, modified, or embedded, and no wordmark is used. This project is not affiliated with DeepSeek; the brand and its marks belong to DeepSeek.
- **The companion desktop pet's assets are not reusable.** That project's own notice forbids commercial use of its artwork and requires attribution, and its pet is soft-shaded animation rather than pixel art. None of it is copied here, which is a second reason the artwork is generated from scratch.

## Size

Measured by `--report`, at the 64 × 64 output size:

| Item | Value |
| --- | --- |
| One frame, RGB565 plus an 8-bit alpha plane | 12,288 B |
| Eleven frames | 132 KiB |
| Opaque pixels, one frame | about 1,400 of 4,096 |

132 KiB of sprite data in flash is not a constraint against 8 MB. RAM is: these
are meant to be drawn straight from flash by LVGL, so the runtime cost is the
draw buffer that already exists, not the sprite size.

## Regenerate

```bash
python generate_pet.py --report --out .          # frames plus a size report
python generate_pet.py --scale 8 --out preview   # large frames for eyeballing
```

The script uses the Python standard library only — no image library, no network —
so the output is reproducible on any machine with Python 3.

## Integration

These PNGs are the reviewable source. On the firmware branch they are converted
into LVGL image descriptors and either stored as RGB565A8 or quantised to an
indexed format; that converter and its exact command belong in the firmware
branch's asset pipeline and must be recorded there together with the LVGL version
it targets.

Binary art lives beside this document because fork-owned material must stay under
`docs/assets/` while this branch tracks upstream. The build-time converter, and
any move of the generated assets into the repository-root `assets/` tree, belong
to the `feature/*` firmware branch.
