# 宠物精灵图设计与生成脚本

本目录存放宠物的像素画以及生成它的脚本。脚本是唯一事实来源：PNG 文件是构建产物，用一条命令即可重新生成，可以安全删除。

该设计是**原创美术**。它是对 DeepSeek 品牌蓝的呼应，而不是对 DeepSeek 标识或任何第三方角色的复制。

> **状态：** 第一版设计，等待产品负责人验收确认。重绘成本很低 —— 修改几何常量并重新运行生成脚本即可。

## 设计

一只朝右的 Q 版鲸鱼，采用四分之三视角：双眼都可见，因此宠物能够表演；尾鳍位于左后方；宠物说话或高兴时，头部上方会出现喷水。

| 属性 | 数值 |
| --- | --- |
| 逻辑网格 | 32 × 32 像素 |
| 输出尺寸 | 64 × 64 像素（整数倍 2× 缩放，因此每个逻辑像素是 4 像素见方） |
| 朝向 | 横向精灵图，朝右，竖屏屏幕 |
| 轮廓 | 圆润的身体、前部更圆的头部、两瓣尾鳍、小背鳍、前胸鳍、浅色腹部、沿背部的一条亮带 |
| 面部 | 两只 3 × 3 的眼睛，带 2 × 2 瞳孔，可看向四个方向；一个 4 像素的嘴，有四种形状；以及腮红 |
| 描边 | 仅身体周围一圈一个逻辑像素的深藏青色；喷水和睡眠符号等装饰刻意不加描边 |

朝右是刻意为之，理由见[参考调研与独立性](#参考调研与独立性)。

## 调色板

十一个不透明条目加透明。刻意保持精简：颜色更少意味着后续的索引色精灵图数据更小。

| 索引 | 名称 | Hex | 用途 |
| --- | --- | --- | --- |
| 0 | transparent | — | 精灵图之外的一切 |
| 1 | outline | `#101828` | 轮廓边界和面部特征 |
| 2 | body | `#4D6BFE` | 身体主体 —— DeepSeek 品牌蓝 |
| 3 | body-dark | `#2B3A8F` | 保留用于纵深与明暗 |
| 4 | body-light | `#7A92FF` | 沿背部的一条亮带 |
| 5 | belly | `#EAF0FF` | 腹部和嘴部区域 |
| 6 | eye | `#101828` | 瞳孔和嘴 |
| 7 | eye-white | `#FFFFFF` | 眼白 |
| 8 | blush | `#FF9EB1` | 脸颊 |
| 9 | water | `#8FD4FF` | 喷水、聆听波纹、汗滴 |
| 10 | water-light | `#FFFFFF` | 喷水高光 |
| 11 | sleep | `#C8D6FF` | 思维气泡和睡眠符号 |

## 帧与触发时机

| 帧 | 触发时机 |
| --- | --- |
| `idle_a`、`idle_b` | 默认状态；这一对构成两帧的呼吸式上下浮动 |
| `blink` | 以随机间隔插入待机循环 |
| `curious` | 按下 `UP` / `DOWN`，或有新通知 |
| `listening` | 语音采集进行中 |
| `thinking` | 语言模型往返请求进行中 |
| `working` | 智能体任务正在运行；尾部抬起 |
| `speaking` | 回复音频播放中 |
| `happy` | 一轮成功，或工作模式成功 |
| `sleeping` | 屏幕调暗的待机 |
| `distressed` | 网络或服务商故障、电量低 |

## 参考调研与独立性

本设计参考了公开资料，但未从中复制任何内容。

| 调研发现 | 来源 |
| --- | --- |
| 官方品牌色是 `#4D6BFE` | DeepSeek 自己的组织仓库提供了一块色板，其唯一填充值就是该值。此处的身体颜色正是它 |
| DeepSeek 的标识是一条鲸鱼 | 媒体报道将其描述为一条圆胖的亮蓝色鲸鱼，并指出鲸鱼的眼睛在小尺寸下会丢失 —— 这正是本宠物眼睛刻意放大且高对比的原因 |
| 不存在官方的像素画吉祥物 | 官方角色只有标识鲸鱼，因此本项目并未复制已发布的美术作品 |
| 标识鲸鱼朝左，尾鳍在右上方抬起 | 直接查看官方标识的渲染副本 |

由这些发现得出的决定：

- **朝向。** 本宠物朝右。官方标识朝左，完全照搬会使该角色更接近标识轮廓，而轮廓正是 DeepSeek 品牌规则保护力度最大的部分。朝右还让宠物朝向屏幕内容。如果负责人更偏好标识的朝向，这只需改一个常量 —— 见设计一节下的说明。
- **尾部表示正在工作。** DeepSeek 自家的 harness 用动画鲸鱼尾作为其“智能体正在工作”指示。`working` 帧沿用这一惯例，而不是另创一套。
- **没有任何描摹。** 官方轮廓未被描摹、修改或嵌入，也未使用任何文字商标。本项目与 DeepSeek 无隶属关系；品牌及其标识归 DeepSeek 所有。
- **同类桌面宠物项目的素材不可复用。** 该项目自己的声明禁止将其美术作品用于商业用途，并要求署名，而且它的宠物是柔和着色的动画而非像素画。此处未复制其中任何内容，这也是美术需从零生成的第二个原因。

## 体积

由 `--report` 在 64 × 64 输出尺寸下测得：

| 项目 | 数值 |
| --- | --- |
| 单帧，RGB565 加一个 8 位 Alpha 通道 | 12,288 B |
| 十一帧 | 132 KiB |
| 单帧不透明像素 | 4,096 个中约 1,400 个 |

flash 中 132 KiB 的精灵图数据相对 8 MB 并不构成约束。RAM 才是约束：这些数据本意是由 LVGL 直接从 flash 绘制，因此运行时开销是已经存在的绘制缓冲，而不是精灵图的体积。

## 重新生成

```bash
python generate_pet.py --report --out .          # frames plus a size report
python generate_pet.py --scale 8 --out preview   # large frames for eyeballing
```

该脚本只使用 Python 标准库 —— 没有图像库，也没有网络 —— 因此在任何装有 Python 3 的机器上输出都是可复现的。

## 集成

这些 PNG 是可评审的来源。在固件分支上，它们会被转换成 LVGL 图像描述符，要么以 RGB565A8 存储，要么量化成索引色格式；该转换脚本及其确切命令属于固件分支的素材流水线，并且必须连同它所针对的 LVGL 版本一起记录在那里。

二进制美术资源放在本文档旁边，因为 fork 自有素材必须留在 `docs/assets/` 下，而本分支跟踪上游。构建期的转换脚本，以及把生成的素材移入仓库根目录 `assets/` 树的任何操作，都属于 `feature/*` 固件分支。
